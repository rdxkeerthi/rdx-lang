# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.5.x   | :white_check_mark: |
| < 2.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in the RDX Forensics runtime, compiler, or standard primitives:

1. **Do not open a public issue.**
2. Send an email to the security maintainers or open a [Private Security Advisory](https://github.com/rdxkeerthi/rdx-lang/security/advisories/new) on GitHub.
3. Provide a clear description, reproducible `.rdx` code, and the operating system / architecture.

We will acknowledge receipt within 48 hours and work with you on a patch and responsible disclosure timeline.
